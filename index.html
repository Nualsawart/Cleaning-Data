ภารกิจ Data Cleaning
& Data Analysis

เรียนรู้การตรวจสอบ ทำความสะอาด และวิเคราะห์ข้อมูล ผ่านภารกิจที่ต้องใช้เหตุผลและการคิดวิเคราะห์จากข้อมูลจริง

เริ่มต้นภารกิจ
กรอกข้อมูลของตนเองก่อนเริ่มทำแบบฝึกหัด
5 ภารกิจของ Data Analyst
01

Data Detective

ค้นหาข้อมูลที่ผิดปกติและระบุว่าปัญหาของข้อมูลคืออะไร

02

Clean the Data

แก้ไขและจัดรูปแบบข้อมูลให้พร้อมสำหรับการวิเคราะห์

03

Missing Data

วิเคราะห์ข้อมูลที่หายไปและเลือกวิธีจัดการพร้อมอธิบายเหตุผล

04

Data Analysis

วิเคราะห์ข้อมูลหลังทำความสะอาดและตีความผลลัพธ์

05

Data Analyst Challenge

แก้โจทย์สถานการณ์จริงตั้งแต่ตรวจข้อมูลจนถึงเสนอข้อสรุป

สิ่งที่ต้องใช้ในการทำภารกิจ

นักเรียนต้องอธิบายเหตุผลจากข้อมูลจริง ไม่ใช่เพียงเลือกคำตอบ คำตอบปลายเปิดจะได้รับการตรวจตามเกณฑ์การประเมิน และสามารถดูคะแนนกับข้อเสนอแนะหลังส่งคำตอบ
